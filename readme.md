# YouTube Video Analysis Tool 🎥

A streamlined AI tool that automatically analyzes YouTube videos and generates comprehensive summaries using BART Large CNN model.

## Features
- Extracts transcripts from YouTube videos (supports both manual subtitles and auto-generated captions)
- Generates structured analysis including:
  - Main topics covered
  - Detailed summary
  - Key insights and takeaways
  - Technical details
  - Important timestamps
- Uses HuggingFace's BART model for summarization
- Real-time processing with user-friendly interface

## Requirements
- Python 3.8+
- Internet connection for YouTube transcript access
- Supported by Hugging Face Spaces

## Usage
1. Visit the link: https://youtube-video-analyzer-a97uwsq2srgptrczjnmv3s.streamlit.app/
2. Paste a YouTube video URL
3. Click "Analyze Video" to get instant insights

Perfect for researchers, students, and content creators who need quick, detailed summaries of video content.

## Troubleshooting
If you encounter transcript errors:
1. Verify the video has captions enabled
2. Try a different video with English subtitles
3. Ensure the video is not private or age-restricted
